Minecraft Arab
===============

ملفات الموقع:
- index.html: الصفحة الرئيسية ومحتوى الموقع.
- style.css: الألوان والتنسيق والتصميم المتجاوب للهاتف والكمبيوتر.
- script.js: قائمة الهاتف والسنة الحالية.
- README-AR.txt: هذا الملف.

طريقة النشر عبر GitHub Pages:
1. ارفع الملفات الأربعة إلى المستودع minecraft-arab في حسابك.
2. افتح Settings داخل المستودع.
3. اختر Pages من القائمة.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع main والمجلد /(root)، ثم اضغط Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

ملاحظات:
- يجب أن يكون اسم ملف الصفحة الرئيسية index.html كما هو.
- روابط التحميل توجه إلى موقع Minecraft الرسمي أو المتاجر الرسمية.
- مساحات الإعلانات مجرد أماكن مخصصة وليست إعلانات فعالة.
- لا تضع شفرة Google AdSense قبل قبول الموقع والحصول على شفرة الإعلانات من حسابك.
- قبول AdSense غير مضمون، ويحتاج إلى محتوى أصلي مفيد وصفحات وسياسات مناسبة والالتزام بسياسات Google.
- الموقع مستقل وغير تابع إلى Mojang أو Microsoft.
